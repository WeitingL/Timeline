06已確認的決定

1 · 背景

離開畫面就不 tick

produceState 的 coroutine 綁在 composition 上 —— 看得見時永遠正確，看不見時不做事。不加 LifecycleResumeEffect。

2 · 間隔

固定一分鐘

日刻度下一分鐘約 1dp，與紅線的視覺精度相符。綁 pxPerMinute 會精確但過度工程。

3 · 護欄

不加測試，風險已接受

需要 instrumented test + 重組計數，代價是新依賴與新 source set。後果寫在 spec 裡而非默默略過：這一類回歸對 CI 永遠隱形。

4 · 剩下的

寫成 spec 004，不實作

剩餘四項算繪優化寫成文件並標記 parked，讓「我們看過、決定不做」是找得到的，而不是用沉默暗示。
